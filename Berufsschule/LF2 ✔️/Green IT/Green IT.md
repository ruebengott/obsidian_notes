# Green IT

> [!summary] Kurz & knapp
> **Green IT** heißt, Informationstechnik **ressourcenschonend und umweltfreundlich** zu gestalten, und zwar in den drei Bereichen **Hardware, Software und Nutzung**. Denn „Digital ist physisch“: Internet und Cloud bestehen aus Servern, Leitungen und Kühlung, die viel Energie und Rohstoffe verbrauchen. Green IT ist ein angekündigtes **Klausurthema**.

## Warum ist das wichtig?
- **Internet = Server + Kabel/Leitungen + Kühlung** → auch „die Cloud“ verbraucht Strom.
- **Rechenzentren** haben einen riesigen Energieverbrauch, und **Streaming und KI** verstärken das Problem.
- Klimawandel, steigender Energiebedarf, **Verantwortung als ITler**: „IT verändert die Welt – auch das Klima“.

## Ziele und Bereiche

| Ziele | Bereiche |
| --- | --- |
| Energie sparen | **Hardware**: effiziente Geräte, lange Nutzung, Recycling |
| Ressourcen schonen | **Software**: effizienter Code (Green Coding), schlanke Anwendungen |
| Umwelt schützen | **Nutzung**: Geräte ausschalten, bewusstes Streaming, Virtualisierung |

## Problemfelder
- **Rechenzentren** (Strom für Server und Kühlung)
- **Elektroschrott** (giftige Stoffe, verlorene Rohstoffe, Export in Entwicklungsländer)
- **ineffiziente Software** (unnötig hohe Rechenlast)
- **Dauerbetrieb** und Standby (Gaming-PCs stundenlang, 4K-Streaming, unnötige Hintergrundprogramme)

## Maßnahmen

| Maßnahme | Beispiel |
| --- | --- |
| Geräte ausschalten | automatische Abschaltung nachts, Steckdosenleisten mit Schalter, kein Dauer-Standby |
| effiziente Software | Green Coding, Abfragen zeitlich reduzieren, Daten komprimieren |
| Virtualisierung | viele virtuelle Server auf wenigen physischen Hosts → bessere Auslastung |
| erneuerbare Energie | Rechenzentren mit Ökostrom, Abwärme nutzen |
| Hardware länger nutzen | Reparatur und Aufrüstung statt Neukauf, Refurbished-Geräte |
| effiziente Hardware | Netzteile mit hohem [[Wirkungsgrad]] (80 PLUS), Energiesparmodi, SSD statt HDD |
| fachgerechte Entsorgung | Elektroschrott-Recycling (Kupfer, Gold, seltene Erden) |

## Gruppenarbeit: Energieverschwendung und Verbesserungsideen (Mitschrift)

| Energieverschwendung | Verbesserungsidee |
| --- | --- |
| Maschinen im Dauerbetrieb (Monitoring, Drucker) | automatisierte Abschaltsysteme |
| Server und API-Daueranfragen | Anfragen zeitlich reduzieren (bündeln, cachen) |
| Geräte dauerhaft im Standby | Geräte komplett abschalten, wenn sie nicht gebraucht werden |
| – | Energiesparmodi nutzen |

**Land (Förderung):** Bezuschussung für Projekte, die sich an Green-IT-Richtlinien orientieren (Green Coding). Das Land investiert etwa **10 Mio. €** in **46 Maßnahmen** (z. B. Optimierung von Rechenzentren, energieeffiziente Hardware), um bis zu **2.400 MWh pro Jahr** einzusparen.

- schlägt **Verbesserungen** vor

- arbeitet auf Basis von Standards/Richtlinien zur Nachhaltigkeit

## Lernfragen
> [!question]- Was versteht man unter Green IT?
> Die umwelt- und ressourcenschonende Gestaltung von IT über den gesamten Lebenszyklus (Herstellung, Nutzung, Entsorgung) in den Bereichen Hardware, Software und Nutzung.

> [!question]- Warum ist auch „die Cloud“ nicht automatisch umweltfreundlich?
> Die Cloud besteht aus Rechenzentren mit Servern, Netzwerktechnik und Kühlung, die viel Strom und Rohstoffe verbrauchen („Digital ist physisch“).

> [!question]- Nenne vier Green-IT-Maßnahmen für ein Büro.
> Geräte nachts automatisch abschalten statt Standby, energieeffiziente Hardware/Netzteile, Server virtualisieren, Hardware länger nutzen bzw. reparieren, Ökostrom, Elektroschrott fachgerecht entsorgen.

> [!question]- Wie trägt Virtualisierung zu Green IT bei?
> Mehrere virtuelle Server laufen auf einem physischen Host. Dadurch sind weniger Geräte nötig, die Auslastung ist besser und Strom- und Kühlbedarf sinken.

> [!question]- Welche Problemfelder der IT nennt die Präsentation?
> Rechenzentren, Elektroschrott, ineffiziente Software und Dauerbetrieb.
