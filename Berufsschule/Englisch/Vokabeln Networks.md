# Vokabeln Networks

> [!summary] Kurz & knapp
> Netzwerk-Fachwortschatz aus dem Arbeitsblatt „Networks“ (IT023), der Network FAQ und deiner Hausnetz-Skizze.

## Komponenten und Geräte
| English | Deutsch | Beispiel |
|---|---|---|
| network interface card (NIC) | Netzwerkkarte | *If the built-in NIC is broken, you can install a new one.* |
| network switch | Switch | *A switch interconnects various network devices.* |
| hub | Hub | *Hubs have largely been replaced by switches.* |
| router | Router | *The router connects the LAN to the Internet.* |
| modem | Modem | *The modem connects to the DSL line.* |
| wireless access point (AP) | WLAN-Zugangspunkt | *Laptops connect to the wireless access point.* |
| server | Server | *The server stores and distributes information.* |
| server room | Serverraum | *The server room is air-conditioned.* |
| server rack | Serverschrank | *The servers are mounted in a server rack.* |
| patch panel | Patchfeld | *All cables end at the patch panel.* |
| NAS (network attached storage) | Netzwerkspeicher | *We back up our photos to the NAS.* |
| crimping tool | Crimpzange | *This is a tool for crimping your own network cable.* |
| Ethernet cable | Netzwerkkabel | *Plug the Ethernet cable into the router.* |
| fibre / fiber optic cable | Glasfaserkabel | *Fibre optic cables are very fast.* |
| port | Anschluss, Port | *The switch has 48 ports.* |
| utility room | Technikraum, Hauswirtschaftsraum | *The router is in the utility room.* |

## Begriffe
| English | Deutsch | Beispiel |
|---|---|---|
| to interconnect | miteinander verbinden | *A network interconnects computers.* |
| to share resources | Ressourcen gemeinsam nutzen | *The purpose of a network is to share resources.* |
| node | Knoten (Netzwerkteilnehmer) | *Each computer is a node.* |
| client-server network | Client-Server-Netz | *One computer acts as a server.* |
| peer-to-peer network | Peer-to-Peer-Netz | *All computers have the same capabilities.* |
| topology / layout | Topologie, Aufbau | *bus, star, ring, tree, mesh topology* |
| protocol | Protokoll | *The Internet uses TCP/IP.* |
| PAN / LAN / MAN / WAN | persönliches / lokales / Stadt- / Weitverkehrsnetz | *A WAN covers a country or a continent.* |
| ISP (Internet Service Provider) | Internetanbieter | *Log on to your ISP with username and password.* |
| broadband | Breitband | *a broadband internet connection* |
| bandwidth | Bandbreite | *All hosts share the bandwidth.* |
| latency | Latenz, Verzögerung | *Satellite links have high latency.* |
| interference | Störung (Funk) | *Wireless networks are subject to interference.* |
| to roam | (zwischen APs) wechseln | *You can roam from one access point to another.* |
| reliable | zuverlässig | *Wired LANs are more reliable.* |
| single point of failure | einzelne Fehlerquelle | *The central hub is a single point of failure.* |
| to log on / to log off | anmelden / abmelden | *Remember to log off.* |

> [!note] Rechtschreibung aus deinen Notizen
> „Batch Panel“ → **patch panel** · „Serverrack“ → **server rack** · „livingroom“ → **living room** · „bedrocm“ → **bedroom**.

> [!tip] Merke
> **patch** panel (to patch = flicken/verbinden), nicht *batch*. Britisch **fibre**, amerikanisch **fiber**.

## Lernfragen
> [!question]- What's the English word for „Netzwerkkarte“?
> *network interface card (NIC)*

> [!question]- What's the English word for „Patchfeld“?
> *patch panel*

> [!question]- What's the English word for „Crimpzange“?
> *crimping tool*

> [!question]- What's the English word for „Bandbreite“?
> *bandwidth*

> [!question]- What's a „single point of failure“?
> Ein einzelnes Bauteil, dessen Ausfall das ganze System lahmlegt.
