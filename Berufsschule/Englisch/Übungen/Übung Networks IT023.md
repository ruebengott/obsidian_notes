## Task 2 – Jumbled descriptions (korrigiert)
1. **Server room:** *A server room is a room which houses multiple servers. The room is air-conditioned and often has a fire protection system.*
2. **Network switch:** *This device interconnects various other network devices. It can easily have ports for up to 256 cables.*
3. **Network interface card:** *This is your computer's or server's built-in network connection. If it is broken, you can install a new one.* (alternativ: *If your computer's or server's built-in network connection is broken, you can install this.*)
4. **Crimping tool:** *This is a tool for crimping your own network cable.* ✔ (handschriftlich korrekt)

## Task 3 – Name the network components
Deine Einträge: (2) Serverrack, (3) Switch, (6) Router.

| Nr. | Lösungsvorschlag | Function |
|---|---|---|
| (2) | **server** (in a server rack) | *stores and distributes data and services to the clients* |
| (3) / (5) | **switch** (or hub) | *connects the wired devices of the LAN and forwards data to the right device* |
| (4) | **modem / router** | *connects the LAN to the Internet (ISP)* |
| (6) | **wireless access point** (wireless router) | *connects wireless devices (laptop, PDA, console) to the LAN* |

> [!question]- Unsicher
> Die Nummerierung (3) und (5) zeigen im Bild auf dasselbe Gerät; die genaue Musterlösung des Lehrers liegt nicht vor. Das Gerät mit Antennen (6) ist eher ein **wireless access point** als ein klassischer Router.

## Task 4/5 – Network FAQ
![[Technisches Englisch.pdf#page=19]]

| Question | Answer |
|---|---|
| What does PAN stand for? | *Personal Area Network.* |
| What is a network protocol? | *The language, or set of rules, that computers use to communicate with each other.* |

| What is WiMAX used for? | *For connecting Wi-Fi hotspots.* |

## Task 6 – Bring the text up to date (Lösungsvorschlag)
| Veraltet | Heute |
|---|---|
| PANs include a laptop, a mobile phone and a **PDA** | PDAs gibt es nicht mehr → smartphone, tablet, smartwatch, wireless earbuds |
| modem router: phone cord into the **ADSL port**; ISP's **name and phone number** | VDSL/fibre/cable; Zugangsdaten statt Einwahlnummer; Router oft vom Provider vorkonfiguriert |
| **hub** | Hubs sind veraltet → switches |
| „remember to **log off** … an open line increases the risk of viruses“ | Verbindungen sind dauerhaft online (*always on*); Schutz durch Firewall, Updates, Antivirus |
| **RSS feeds**, newsletters | eher Social Media, Push-Benachrichtigungen, Podcasts |
| **WiMAX** for connecting hotspots | WiMAX ist kaum noch verbreitet → 4G/5G |
| **GSM** for mobile phones | 4G (LTE) / 5G |
| wireless less secure | mit WPA3-Verschlüsselung deutlich sicherer, aber weiterhin anfälliger als Kabel |

## Lernfragen
> [!question]- What is a crimping tool used for?
> *For crimping (attaching) connectors to your own network cables.*

> [!question]- Which device connects the LAN to the Internet?
> *The router (with modem).*
