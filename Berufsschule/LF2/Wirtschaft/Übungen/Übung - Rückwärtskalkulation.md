# Übung - Rückwärtskalkulation

> [!summary] Kurz & knapp
> Zwei Rückwärtskalkulationen (S. 101–102): Aus einem vom Kunden geforderten Bruttopreis werden Bezugspreis und Listeneinkaufspreis ermittelt. Jeder Zwischenschritt wird kaufmännisch auf zwei Nachkommastellen gerundet.

## Aufgabe a
Kunde fordert 198,00 € (inkl. USt), 20 % Kundenrabatt, 3 % Kundenskonto. Gewinnaufschlag 12 %, Handlungskostensatz 50 %, Lieferfracht 8,00 €, Liefererrabatt 15 %, Liefererskonto 3 %.

> [!success]- Lösung
> | Schritt | Satz | Betrag | Rechenweg |
> |---|---|---|---|
> | Listen-VK inkl. USt | | 198,00 € | |
> | − Umsatzsteuer | 19 % | 31,61 € | 198 · 19 / 119 |
> | = Listenverkaufspreis | | 166,39 € | |
> | − Kundenrabatt | 20 % | 33,28 € | 166,39 · 20 / 100 |
> | = Zielverkaufspreis | | 133,11 € | |
> | − Kundenskonto | 3 % | 3,99 € | 133,11 · 3 / 100 |
> | = Barverkaufspreis | | 129,12 € | |
> | − Gewinn | 12 % | 13,83 € | 129,12 · 12 / 112 |
> | = Selbstkosten | | 115,29 € | |
> | − Handlungskosten | 50 % | 38,43 € | 115,29 · 50 / 150 |
> | = **Bezugspreis** | | **76,86 €** | |
> | − Bezugskosten | | 8,00 € | |
> | = Bareinkaufspreis | | 68,86 € | |
> | + Liefererskonto | 3 % | 2,13 € | 68,86 · 3 / 97 |
> | = Zieleinkaufspreis | | 70,99 € | |
> | + Liefererrabatt | 15 % | 12,53 € | 70,99 · 15 / 85 |
> | = **Listeneinkaufspreis** | | **83,52 €** | |
>
> > [!warning] Korrektur
> > Bis zum Bareinkaufspreis (68,86 €) ist die Mitschrift richtig. Danach: Skonto 68,86 · 3/97 = 2,1297 → **2,13 €** (nicht 2,12 €), ZEP **70,99 €**; Rabatt 70,99 · 15/85 = **12,53 €** (in der Mitschrift 11,80 € und LEP 82,78 € bzw. 83,32 €). Richtiger Listeneinkaufspreis: **83,52 €**.
